Fit SIR model
-------------

As part of my Python learning, I coded this little app, that generates simulated data of an infectious disease wave and then fits a simple [SIR model](https://en.wikipedia.org/wiki/Compartmental_models_in_epidemiology#The_SIR_model_without_vital_dynamics). The user can choose between steepest descent and congugate gradient methods in a GUI.  
The source code is openly available at https://github.com/frank-roesler/SIR_fit
